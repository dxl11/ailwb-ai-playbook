# 大学生论文选题 AI 指令 实战手册

## 从专业方向到最终选题的完整操作流程

## 一、先理解：论文选题到底要解决什么问题？

一个合格的论文选题，至少要回答六个问题：

1. **研究什么？** 研究对象、现象、变量或文本是什么？
2. **为什么研究？** 这个问题是否有现实意义、理论价值或专业价值？
3. **别人研究到什么程度了？** 已有研究有哪些主要观点、方法和发现？
4. **还有什么问题值得进一步研究？** 是研究对象不同、研究情境不同、观点存在争议，还是现有方法存在局限？
5. **准备怎样研究？** 能否找到资料、样本、数据、案例或原始文本？
6. **自己能否完成？** 研究范围、专业能力、时间和资源是否匹配？

选题时，不要只要求 AI 回答“给我推荐 20 个论文题目”。这种提问往往只能得到一组听起来合理、实际上未必有研究价值或可操作性的标题。

正确做法是把选题拆成多个环节，逐步推进。

建议按照以下顺序操作：

**了解自身条件 → 明确研究方向 → 形成问题线索 → 检索已有研究 → 识别潜在研究空间 → 评估可行性 → 收窄范围 → 确定研究问题 → 形成最终选题。**

这份手册中的 Prompt 可以分开使用，也可以在同一段对话中依次使用。

# 二、开始之前：给 AI 提供必要的背景信息

AI 的回答质量，在很大程度上取决于你是否提供了足够具体的信息。

在使用后面的选题 Prompt 之前，先准备以下材料。

| 信息        | 你需要填写什么                                   | 为什么重要               |
| ----------- | ------------------------------------------------ | ------------------------ |
| 所学专业    | 例如工商管理、汉语言文学、计算机科学与技术       | 确定选题的专业边界       |
| 学历阶段    | 本科毕业论文、课程论文等                         | 决定研究难度与深度       |
| 学校要求    | 字数、提交时间、选题限制、方法要求               | 避免生成不符合要求的题目 |
| 个人兴趣    | 感兴趣的行业、现象、问题或领域                   | 提高持续研究的意愿       |
| 已学课程    | 统计学、管理学、法学、文学理论等                 | 判断专业知识是否足够     |
| 研究方法    | 问卷、访谈、案例研究、文本分析、实验、程序实现等 | 决定题目能否落地         |
| 数据资源    | 是否能获取企业资料、公开数据、受访者或实验条件   | 判断研究能否开展         |
| 时间预算    | 剩余周数、每周能投入多少时间                     | 控制题目规模             |
| 已有基础    | 读过的论文、课程作业、实习或项目经验             | 寻找更具体的问题线索     |
| AI 使用规定 | 学校对选题、检索、分析等环节的规定               | 明确允许使用 AI 的边界   |

如果暂时不知道某些信息，可以填写“不确定”，不必为了完成表格而编造条件。

## 指令01：建立论文选题背景档案

**适用阶段：第一次使用 AI 时。**

**目的：** 让 AI 了解你是谁、研究条件如何，以及后续建议需要遵守哪些限制。

复制以下提示词：

你现在需要根据我的真实学习情况和学校要求，帮助我开展论文选题前期准备。

请注意：你必须先检查我提供的学校 AI 使用规定。只有在相关规定允许的情况下，才能协助生成或比较具体选题。如果规定不清楚，请明确标记为“需要确认”，不要默认所有用途都被允许。

我的基本情况如下：

- 所学专业：【填写专业】
- 学历阶段：【例如本科毕业论文】
- 论文类型：【理论研究、实证研究、案例研究、设计开发、其他】
- 学校对论文的基本要求：【填写】
- 学院或指导教师提出的选题要求：【填写】
- 当前已知的 AI 使用规定：【粘贴具体规定；不清楚则填写“不清楚”】
- 我比较感兴趣的领域：【填写，可以有多个】
- 我不感兴趣或不愿意研究的领域：【填写】
- 我学过的主要课程：【填写】
- 我擅长的研究方法或工具：【填写】
- 我不熟悉的研究方法或工具：【填写】
- 目前可以获取的资料、数据或研究对象：【填写】
- 是否具有企业、学校、社区、机构等调研渠道：【填写】
- 预计完成时间：【填写】
- 其他限制：【填写】

请先不要直接生成最终论文题目。

第一步，请整理我的个人研究条件，包括专业优势、兴趣基础、研究能力、数据资源和现实限制。

第二步，请区分以下内容：

1. 已经明确的事实。
2. 仍然不确定的信息。
3. 可能影响选题的关键限制。
4. 需要我自行确认的条件。

第三步，请判断我适合优先考虑哪些研究类型，例如文献研究、案例研究、问卷调查、访谈研究、实验研究、数据分析、文本分析或设计开发。

第四步，请说明每种研究类型需要什么资料、专业知识和工作量，不能仅因为某种方法流行就建议我使用。

第五步，在得到允许后续开展选题探索的明确条件之前，请不要将推测当成事实。

请使用清晰的表格输出，并给出下一步最值得解决的三个问题。

输出原则：不夸大我的能力，不虚构我的资源，不默认我能够获取任何数据，也不把复杂研究方法包装成容易完成的任务。

**使用技巧：** 这个 Prompt 的重点不是立即得到题目，而是建立一份真实的研究条件档案。后面每一步都应该以这份档案为基础。

# 三、阶段一：找到适合自己的研究方向

很多大学生的困难，不是想不出题目，而是只知道专业名称，不知道自己究竟可以研究什么。

例如，工商管理涉及人力资源、组织行为、市场营销、运营管理、战略管理等方向。“研究企业管理”仍然太宽泛，需要继续向下拆解。

## 指令 02：从专业知识中寻找研究方向

**适用阶段：不知道该研究什么。**

请根据我的专业情况，帮助我建立一个有层次的论文研究方向地图。

我的信息如下：

- 专业：【填写】
- 研究阶段：【填写】
- 比较感兴趣的课程：【填写】
- 比较熟悉的现实场景：【填写】
- 具备的资料或研究资源：【填写】
- 学校规定的限制：【填写】

请按照以下步骤完成分析。

### 第一步：拆解专业领域

将我的专业拆分为若干主要研究方向，每个方向至少列出三个具体的子方向。

不要停留在“教育研究”“企业管理”“文学研究”这样的宽泛标签上。

### 第二步：寻找可以被研究的问题

针对每个子方向，分别从以下角度提出问题线索：

- 现实生活中存在的现象。
- 实践过程中遇到的困难。
- 不同群体之间的差异。
- 某种现象产生的原因。
- 某项政策或措施实施后的变化。
- 现有观点之间的争议。
- 不同案例之间的差异。
- 现有研究可能存在的适用条件或局限。

这里的输出应当是“值得调查的问题线索”，而不只是换了措辞的论文标题。

### 第三步：匹配我的实际条件

为每条问题线索标注：

- 专业匹配程度。
- 对相关知识的要求。
- 可能采用的研究方法。
- 必需的数据或资料。
- 获取这些资料的难度。
- 可能遇到的伦理或权限问题。
- 适合作为本科论文的程度。

### 第四步：形成候选方向

请优先筛选出与我的兴趣、专业基础和现有资源相匹配的方向。

不要把“热门”“容易通过”“网上资料很多”直接等同于研究价值。

最终请提供一张研究方向地图，并从中筛选出值得进一步考察的方向。

请将“根据常识提出的初步猜想”和“已有文献证实的研究现状”分开标记，不能在尚未检索文献时宣称某个方向存在研究空白。

## 指令 03：通过兴趣反推选题方向

**适用阶段：对专业了解有限，不确定自己喜欢什么。**

我现在不确定自己真正适合研究什么。请你暂时不要替我决定题目，而是通过一系列有针对性的问题，帮助我发现可能的研究兴趣。

请从以下维度依次提问：

1. 我平时会主动关注什么现象？
2. 哪些课程或专业知识让我产生过疑问？
3. 我是否发现过某种值得解释的现实矛盾？
4. 我有没有接触过值得分析的企业、作品、社会群体或技术？
5. 哪些问题是我愿意花几周时间查资料的？
6. 我更倾向于解释原因、比较差异、评价效果、分析文本，还是设计并实现某种方案？
7. 我更擅长阅读、写作、交流、统计、编程、实验，还是案例分析？
8. 我有哪些明确不能突破的资源限制？

每次可以提出三个相关问题，根据我的回答逐步缩小范围。

完成了解后，请输出：

- 我的兴趣主题。
- 兴趣背后对应的专业问题。
- 可能的研究方向。
- 每个方向对应的研究对象。
- 进一步验证该方向所需的资料。
- 当前仍然存在的不确定因素。

不要仅根据我的兴趣推断我有足够的研究能力；也不要为了迎合我而把任何兴趣包装成有创新价值的学术选题。

## 指令 04：把热点话题转化为研究问题

**适用阶段：发现某个热门领域，想围绕它开展研究。**

我关注的领域是：【填写，例如人工智能对企业工作的影响】。

请不要直接把这个热点写成论文题目，而是按照“宏观话题—具体现象—研究对象—具体问题—可验证的问题”逐步拆解。

请分别识别以下几类研究切入点：

1. **对象切入：** 不同群体、组织或场景之间是否存在值得解释的差异？
2. **机制切入：** 某种现象可能通过什么过程发生？现有理论能否解释？
3. **情境切入：** 某个已有结论是否可能受特定条件影响？
4. **方法切入：** 现有研究的方法是否适合解决该问题？是否有必要采用其他方法？
5. **应用切入：** 实践中存在什么尚未得到充分解决的具体问题？
6. **争议切入：** 不同研究或实践观点之间有哪些分歧，分歧是否来自不同条件或证据？

每个切入点请给出：

- 具体的问题表述。
- 为什么值得调查的初步理由。
- 需要检索的关键词。
- 可能的研究对象。
- 可以使用的证据或资料。
- 适合的研究方法。
- 目前尚未得到验证的假设。

请特别注意：

- 热门不等于创新。
- 新概念不等于新问题。
- 在某个行业首次使用某项技术，不等于已经具备学术创新价值。
- 如果没有查阅相关研究，不要断言某个切入点“国内外首次研究”或“完全没有人研究”。

最终请保留问题线索，而不是急于确定标题。

# 四、阶段二：把宽泛主题转化为具体的问题

选题中最常见的问题，就是题目听起来很专业，却没有明确的研究对象、研究边界和需要回答的问题。

例如：

- 宽泛主题：人工智能与大学生。
- 更具体的现象：大学生使用生成式 AI 辅助学习。
- 研究问题线索：不同使用方式是否与学习投入存在差异？
- 需要核查的研究问题：在明确学生年级、课程情境和使用方式的前提下，现有研究如何测量这种关系？已有结论是否一致？能否获取可靠数据？

注意，最后一个问题只是示例，并不代表相关关系确实存在，更不代表其中存在研究空白。

## 指令 05：将宽泛主题拆解为具体研究问题

我准备进一步研究的主题是：【填写】。

请你帮助我将该主题转化为一组具体、清楚且具有研究可能性的候选问题。

请依次执行以下任务。

**任务一：界定主题。**

明确这个主题中的核心概念、可能的研究对象、发生场景和主要问题。

如果主题中存在含义模糊的词语，请指出不同解释可能导致的研究范围差异。

**任务二：拆分问题。**

围绕该主题提出若干不同类型的问题，至少包括：

- 描述性问题：某种现象呈现出什么特征？
- 比较性问题：不同群体、时期或案例之间有什么差异？
- 解释性问题：哪些因素可能解释某种现象？
- 机制性问题：某种关系可能通过什么过程发生？
- 评价性问题：某项政策、产品或措施取得了什么效果？
- 应用性问题：具体实践中存在哪些待解决的问题？

不是每种问题都适合当前主题，请根据研究条件判断是否适用。

**任务三：检查可研究性。**

针对每个候选问题，回答：

1. 能否明确界定研究对象？
2. 能否提出可回答的问题，而不是抽象口号？
3. 是否能找到相关理论或前期研究？
4. 是否存在可获取的证据？
5. 是否需要超出本科阶段能力的模型、实验或数据？
6. 是否存在伦理、隐私、权限或数据合规风险？

**任务四：形成候选问题清单。**

请用表格输出：

| 候选问题 | 研究对象 | 关键概念 | 所需证据 | 方法方向 | 主要风险 |
| -------- | -------- | -------- | -------- | -------- | -------- |
|          |          |          |          |          |          |

请不要将“提高水平”“促进发展”“完善机制”等目标性口号当作已经明确的研究问题。

如果某个问题暂时无法回答，请指出缺少什么证据，而不是替我编造结论。

## 指令 06：识别问题中的真正矛盾

我现在关注的现象是：【填写具体现象】。

请帮助我判断，这个现象是否包含值得研究的矛盾、差异或解释难题。

请从以下方面分析：

1. 现实目标与实际表现之间是否存在差距？
2. 理论预期与实践表现之间是否可能存在差异？
3. 不同研究是否报告过不一致的结果？
4. 不同群体或情境是否可能呈现不同表现？
5. 某项措施在不同条件下是否可能产生不同结果？
6. 某个现象是否被过度简化，导致其内部差异被忽略？

对每个可能的矛盾，请给出：

- 矛盾的准确表述。
- 支持这一问题存在的证据类型。
- 需要检索的研究。
- 可能的替代解释。
- 哪些结果会削弱这一问题的研究价值。
- 能否形成具体的研究问题。

严格区分“我观察到的现象”“已有文献报告的发现”和“为了后续研究提出的假设”。

没有事实或文献依据的地方，请标记为待验证。

## 指令 07：判断一个题目是不是太大

我目前考虑的选题是：【填写题目或研究方向】。

请从本科论文的完成条件出发，评估它是否存在研究范围过大的问题。

请检查以下维度：

- 研究对象是否过于广泛。
- 是否同时涉及多个独立问题。
- 是否包含过多核心变量或理论。
- 是否跨越过多地区、行业、群体或时间范围。
- 是否需要大量不可获取的数据。
- 是否需要复杂的技术方法或难以完成的实验。
- 是否容易写成介绍现状、罗列问题、提出建议的泛泛文章。

然后，请依次提出三个收窄层次：

**第一层：** 缩小研究对象。

**第二层：** 限定具体情境、时间范围、案例范围或关键问题。

**第三层：** 将研究目标缩小为一个可由有限证据回答的核心问题。

请对每个层次说明，它减少了什么工作量，又可能牺牲了什么研究价值。

最后给出若干可供进一步核查的题目方向，并明确哪些选择依赖于尚未核实的资料条件。

不要仅仅通过增加“以某某为例”就认定题目已经足够具体。

# 五、阶段三：用文献检索判断题目是否值得研究

这是整个选题工作中非常关键的一步。

AI 可以帮助你生成关键词、搭建检索策略、整理文献、归纳可能的争议。但必须注意：**AI 说某个领域“研究较少”，不等于这个领域真的研究较少。**

如果没有实际检索相关文献，AI 不能可靠地替你确认研究空白。它给出的作者姓名、论文标题、期刊、年份和 DOI 也可能有错误。

这一阶段最好让 AI 基于你实际找到的论文、摘要、检索结果或全文开展工作。

## 指令 08：生成学术数据库检索策略

我的专业是：【填写】。

我的候选研究方向是：【填写】。

我目前考虑的问题是：【填写】。

请你为我制定一套可在学术数据库中执行的检索策略。

### 一、提取核心概念

将问题拆解为若干核心概念，找出：

- 核心概念及其定义。
- 常见同义词。
- 学术术语与日常表达之间的区别。
- 相关理论名称。
- 与研究问题有关的变量、对象或场景。

# 六、阶段四：系统评估候选选题是否可行

## 指令 12：论文选题综合可行性评分

请以本科论文指导的标准，评估以下候选题目。

候选题目：【填写】

补充信息：

- 专业与研究阶段：【填写】
- 预计论文篇幅：【填写】
- 剩余时间：【填写】
- 已有相关文献：【填写】
- 可获取的数据和资料：【填写】
- 计划采用的方法：【填写】
- 个人能力与工具基础：【填写】
- 学校及学院要求：【填写】

请使用以下评分框架。

| 评价维度         | 权重 | 重点检查内容                 |
| ---------------- | ---- | ---------------------------- |
| 专业匹配度       | 15%  | 是否属于专业培养范围         |
| 研究价值         | 15%  | 是否值得分析与解释           |
| 文献基础         | 15%  | 是否存在可靠的相关研究基础   |
| 数据与资料可得性 | 15%  | 是否能获得必要证据           |
| 方法可操作性     | 10%  | 是否掌握或能合理学习所需方法 |
| 研究范围合理性   | 10%  | 是否能够明确限定研究边界     |
| 潜在创新空间     | 10%  | 是否有可检验的增量贡献       |
| 时间与资源匹配   | 5%   | 是否能在规定时间内完成       |
| 伦理与合规性     | 5%   | 是否存在无法解决的合规障碍   |

每个维度按照 1—5 分评分。

计算方式为：

**综合分 = 各维度得分 ÷ 5 × 对应权重，然后将所有维度加总。**

总分为 100 分。

请严格执行以下规则：

1. 没有证据支持的维度，不要随意打高分。
2. 无法确认的数据可得性应标记为“待核实”，并说明评分的不确定性。
3. 伦理、隐私、权限或学校规定方面存在无法解决的障碍时，即使总分较高，也不能推荐直接开展研究。
4. 潜在创新空间的评分仅代表当前判断，不能替代文献核查。
5. 不同题目的评分应使用相同标准。

请输出每个维度的分数、评分理由、证据依据和待核实事项。

最后给出：建议继续、修改后继续、补充证据后再判断，或暂时放弃。

不要为了显得专业而把所有候选题目都评为高分。

# 七、阶段五：把候选题目收敛成最终题目

## 指令 15：对论文标题进行多轮收敛

我的候选研究方向是：【填写】。

目前已经明确的条件：

- 研究对象：【填写】
- 具体情境或研究范围：【填写】
- 核心研究问题：【填写】
- 相关理论或概念：【填写】
- 可获取的材料或数据：【填写】

### 第一轮：确定必要信息

判断题目是否需要包含：

- 研究对象。
- 核心问题或关系。
- 研究情境。
- 特定案例或时间范围。
- 理论视角。
- 研究方法。

不是所有题目都必须包含以上全部元素，请说明每个元素是否确实有助于界定研究范围。

### 第二轮：生成不同表达形式

在符合学校规定的前提下，围绕同一个已明确的问题，提出若干不同的标题表达方式。

每个表达必须对应同一个真实可研究的问题，不得通过换一个更专业的说法掩盖研究问题不明确的问题。

### 第三轮：检查标题质量

逐一检查：

1. 是否有宽泛、模糊或无法定义的词语？
2. 是否有多个难以兼顾的研究目标？
3. 是否存在概念重复？
4. 是否暗示了尚未证实的研究结论？
5. 是否声称研究某种因果关系，但实际方法只能提供相关性证据？
6. 是否需要删除不必要的地域、时间或方法限定？
7. 是否明确对应我的专业和论文要求？

### 第四轮：解释标题与研究内容的一致性

对每个候选标题说明：

- 标题中的每个关键短语对应什么研究内容。
- 预计需要回答的核心问题。
- 实际需要收集的证据。
- 能够完成研究的前提条件。
- 标题仍然存在的风险。

请按“题目表述—研究问题—所需证据—研究方法—主要风险”的形式呈现。

最后提供推荐的修改方向，但不要把标题的语言美观程度当成唯一判断标准。

## 指令 16：检查研究对象、变量和概念是否定义清楚

我的题目是：【填写】。

请帮助我判断题目中的核心概念是否清楚、可识别、可研究。

对于每一个关键概念，请检查：

1. 它在相关学科中有哪些常见定义？
2. 是否存在不同理论传统或不同研究之间的定义差异？
3. 我准备采用哪个定义，理由是什么？
4. 这个概念是否需要拆分为多个维度？
5. 是否存在可观察的指标、文本特征、测量工具或判定标准？
6. 是否能够根据这些指标获取有效证据？
7. 是否容易与相近概念混淆？

请将“理论定义”“本文采用的工作定义”和“实际测量方式”分开。

如果某个概念需要先完成文献检索才能确定，请将其列为待核实事项。

不要擅自为缺乏依据的概念设定标准，也不要把复杂的理论概念简单等同于一个容易测量的指标。

# 八、阶段六：把选题变成清楚的研究问题

确定标题还不够。

一个标题即使写得完整，也可能存在以下问题：不知道要解释什么、没有可以验证的材料、研究目标过多，或者研究方法与问题不匹配。

因此，在确定选题前，建议要求 AI 协助检查研究问题和研究目标之间的关系。

不要为了形成完整框架而增加不必要的研究问题。

## 指令 18：研究问题与研究方法匹配检查

我的核心研究问题是：【填写】。

候选研究对象是：【填写】。

我能够获得的资料包括：【填写】。

我目前考虑的方法是：【填写】。

请判断我的研究问题与研究方法是否匹配。

请依次回答：

1. 该问题究竟需要描述、比较、解释、评价、预测、阐释，还是实现某个技术功能？
2. 该问题需要什么类型的证据？
3. 我实际能够获取的材料能否支持这些证据需求？
4. 当前的方法能回答什么问题，不能回答什么问题？
5. 是否存在更简单但足够有效的方法？
6. 是否存在不必要的统计模型、复杂理论或技术实现要求？
7. 如果研究结果不符合预期，现有方法是否仍能够回答研究问题？

请特别注意因果推断的边界。

例如，横截面问卷中的变量相关关系，通常不能单凭相关系数就证明因果关系。如果研究目标涉及因果解释，请明确说明需要什么额外的研究设计、时间顺序或识别条件。

请最终输出一份“研究问题—证据—方法—结论边界”对照表。

# 九、阶段七：让 AI 严格挑错，而不是一味肯定

很多学生在与 AI 对话时会陷入一个问题：AI 提出了题目，学生表示认可，AI 便继续夸奖这个题目有意义、有创新、有现实价值。

这种对话无法有效改善选题。

正确做法是主动要求 AI 反驳自己的方案，并且要求它说明反驳依据。

## 指令 19：让 AI 扮演严格的论文评审者

我的候选题目是：【填写】。

我选择这个题目的理由是：【填写】。

已有文献和研究条件是：【填写】。

请不要默认我的判断正确，也不要为了满足我而肯定这个题目。

请从以下角色分别审视该选题：

**角色一：学科专家。**

检查研究问题是否属于该学科，专业概念是否准确，选题是否具有明确的学术对象。

**角色二：文献研究者。**

检查我对已有研究的认识是否存在偏差，是否把尚未检索的领域误认为研究空白。

**角色三：研究方法审查者。**

检查研究问题是否能被现有数据和研究方法回答。

**角色四：实际执行者。**

检查我是否真的能在现有时间、技能和资源条件下完成研究。

**角色五：严格的反方审查者。**

尽可能寻找反对该选题的理由，包括选题重复、研究意义不足、核心概念模糊、资料不可得、方法不匹配等。

请输出：

- 最有力的三条支持理由。
- 最有力的五条反对理由。
- 支持和反对理由各自依赖的证据。
- 当前最关键的不确定因素。
- 可以通过什么行动降低不确定性。
- 哪些缺陷可以修改，哪些问题可能导致选题应当被放弃。

最后给出有条件的判断：

- 建议继续研究。
- 修改题目后继续。
- 补充关键证据后再判断。
- 暂时不建议采用。

不要把“理论上可能有意义”当成足够的支持证据。

## 指令 20：要求 AI 检查自己之前的结论

请重新审查你此前针对候选选题给出的所有重要判断。

候选题目：【填写】

请重点查找以下问题：

1. 是否出现没有证据支撑的学术价值判断？
2. 是否将推测写成了事实？
3. 是否声称存在研究空白，但没有系统检索依据？
4. 是否将不确定的参考文献当成真实文献？
5. 是否错误使用了专业概念？
6. 是否推荐了无法获取的资料或样本？
7. 是否忽视了时间、资源、隐私或伦理限制？
8. 是否提出了超出本科论文需要的复杂研究方法？
9. 是否过度强调新颖性，而忽视可完成性？
10. 是否存在题目和研究问题不一致的问题？

请把发现的问题分成：

- 已经可以确认的错误。
- 有较高可能性存在的问题。
- 需要通过外部检索或人工核查才能判断的问题。

对每一项提出修正办法。

如果此前的建议确实不成立，请直接撤回并说明原因，不要为了保持前后回答一致而维护错误结论。

# 十、不同专业的专用选题 Prompt

不同学科的研究逻辑并不相同。同一套选题标准，不能机械地用于全部专业。

下面是可按专业直接套用的模板。

## 1. 经济学、金融学、工商管理、市场营销

我的专业方向是：【填写】。

候选领域是：【填写】。

请结合经济管理类研究的特点，帮助我识别可研究的问题。

重点考虑：

- 企业、消费者、组织或市场中的具体现象。
- 有明确解释价值的管理问题。
- 可以检验的理论关系或合理的比较问题。
- 可获得的公开数据、企业案例或调查样本。
- 合适的研究方法及其适用前提。
- 对实际管理或市场实践的潜在价值。

请特别检查：

1. 题目是否只有现象介绍，没有研究问题？
2. 是否把相关关系直接解释为因果关系？
3. 是否因为容易发放问卷就机械地选择问卷法？
4. 样本是否能代表拟研究的对象？
5. 核心变量是否能清楚定义和测量？
6. 是否具备必要的数据、识别条件或合理的比较基础？
7. 研究结论可能适用于哪些范围，又不能推广到哪些范围？

请提出若干候选问题方向，并标注每个方向所需的数据、研究难度和主要风险。

如果研究需要复杂计量模型，请先评估本科阶段的必要性和可操作性，不要仅为了显得专业而推荐复杂模型。

## 2. 教育学、心理学、社会学

我的候选领域是：【填写】。

请从教育、心理或社会科学的角度，帮我识别具体、可研究的问题。

优先关注：

- 特定群体的行为或经历。
- 不同教育或社会情境的差异。
- 可定义的心理、行为或社会概念。
- 理论与实践之间可以被检验的问题。
- 研究结果之间的差异及其潜在解释。
- 适合本科阶段的访谈、问卷、观察、实验或文献研究。

请重点判断：

1. 研究对象是否明确？
2. 关键概念是否存在可靠的定义和测量工具？
3. 问卷题项是否来源清楚，是否需要授权或经过必要的适配与验证？
4. 研究是否涉及未成年人、敏感个人信息或其他伦理风险？
5. 样本来源是否可靠，是否存在明显的样本偏差？
6. 是否有条件完成知情同意、隐私保护和必要的伦理审查？
7. 研究方法是否足以回答拟研究的问题？

请优先推荐能够在现实资源条件下完成的研究方向，不要为了追求复杂度而要求大型样本、多轮实验或复杂的因果模型。

## 3. 法学

我的专业方向是：【填写，例如民商法、经济法、知识产权法】。

候选问题是：【填写】。

请从法学研究的角度帮助我检查选题。

重点考察：

- 法律关系和法律问题是否明确。
- 是否存在具体的法律规范、制度或争议。
- 相关法律条文、司法解释、规范性文件和裁判文书是否能够取得。
- 不同裁判观点或学术解释之间是否存在需要分析的差异。
- 规范解释、案例分析、比较法研究等方法是否适合该问题。
- 选题是否仅仅停留在普法介绍或法条罗列。

请区分：

1. 现行有效法律规范。
2. 历史法律规范。
3. 司法实践中的实际做法。
4. 学术观点。
5. 仍存在争议的问题。

对于涉及现行法律状态的判断，请提醒我核查权威、最新的法律文本和生效日期。

不要自行编造法条、案例案号或司法观点。对于需要最新法规才能确定的结论，请明确标注待核实。

请根据可获得的规范、案例和研究文献，帮助我识别具有明确法律问题和分析空间的方向。

## 4. 汉语言文学、新闻传播、历史学

我的专业方向是：【填写】。

我感兴趣的作品、作家、历史现象或传播对象是：【填写】。

请从人文社科研究的特点出发，帮助我把兴趣转化为具体问题。

请优先检查：

- 研究对象是否明确。
- 是否有可获得、可核验的一手材料。
- 是否有可解释的文本特征、叙事现象、历史问题或传播机制。
- 是否存在适合采用的理论视角。
- 是否能通过文本细读、历史文献分析、话语分析、内容分析或其他适当方法形成论证。
- 是否会因为对象过大而只能进行概述。
- 是否存在把个人感受当成研究结论的问题。

请区分研究对象的新颖性、解释角度的新颖性和研究方法的新颖性，不要把更换作品、作家或地区本身直接视为创新。

对于文学、传播或历史类研究，不要强行套用问卷、变量和统计模型。请先判断研究问题适合何种证据与方法。

如果依赖历史资料，请说明资料的出处、年代、版本和可靠性需要如何核查。

## 5. 计算机科学、软件工程、人工智能

我的专业方向是：【填写】。

我的技术基础是：【填写编程语言、工具、课程和项目经验】。

我目前关注的技术问题是：【填写】。

请按照计算机类本科论文的要求，帮助我判断该方向是否能够成为一个明确的研究或开发课题。

请检查：

1. 是否存在清楚的技术问题，而不只是开发一个普通应用？
2. 是否可以明确系统功能、输入、输出和使用场景？
3. 是否能建立合理的基线方案或对照方法？
4. 是否有公开数据集、可复现的测试环境或合法获取的数据？
5. 是否具备必要的计算资源、开发时间和技术基础？
6. 能否通过准确率、延迟、资源消耗、可用性、可维护性或其他适当指标评价结果？
7. 预期成果属于系统实现、算法改进、实验比较、工程应用还是理论分析？

请区分：

- 工程实现的工作量。
- 技术方案的研究价值。
- 实验设计的可靠性。
- 对照组是否合理。
- 性能评价是否具有可重复性。

不要将“使用了人工智能”“采用了新框架”“完成了一个系统”直接等同于学术创新。

如果需要比较模型，请说明为什么选择这些基线、使用什么数据和评价指标，以及实验资源是否现实可得。

最终请给出问题定义、成果形式、验证方式和风险清单。

## 6. 会计学、审计学

我的专业方向是：【填写】。

候选研究领域是：【填写】。

请从会计、审计及财务研究的角度评估选题。

优先检查：

- 会计或财务问题是否明确。
- 是否有稳定的理论或规范基础。

- 研究对象是否具备可比性。
- 是否存在行业差异、时期差异或制度背景差异。

请优先考虑能够形成完整证据链、研究范围适当的选题。

## 7. 艺术设计、建筑、工业设计、视觉传达

我的专业方向是：【填写】。

我的研究对象或设计方向是：【填写】。

请结合本专业的特点，帮助我区分论文研究问题与设计创作任务。

请重点检查：

- 是否存在明确的设计问题或理论问题。
- 是否能解释设计需求、用户需求或使用情境。

# 十一、阶段八：形成可以用于选题论证的材料

当一个题目经过了文献核查和可行性评估之后，就可以整理出一份清楚的选题论证材料。

这里的目标不是让 AI 代写开题报告，而是帮助你检查论证是否完整，方便你用真实文献和自己的判断进行完善。

## 指令 21：生成一页纸选题论证提纲

我的候选题目是：【填写】。

我的研究背景与相关文献材料是：【粘贴真实材料】。

我已经明确的研究条件是：【填写】。

请根据这些材料，整理一份用于讨论选题的“一页纸研究方案提纲”。

包括以下部分：

**一、候选题目**

给出当前题目，并指出尚未完全明确的概念或范围。

**二、研究背景**

列出现实问题或学术问题的具体表现。相关事实需要有真实来源，不能仅凭常识推断。

**三、研究问题**

使用明确、可回答的句子说明本研究准备解决什么问题。

**四、已有研究基础**

概括我提供的真实文献涉及的主要主题、理论、方法及发现。

**五、潜在研究价值**

说明预期能够增加什么理解、比较、解释或实践认识。没有经过验证的创新点应标为待核实。

**六、研究对象与范围**

说明研究对象、时间、场景及范围边界。

**七、资料与方法**

列出需要的材料、数据来源和适用方法，并说明获取条件。

**八、主要风险**

指出数据、方法、时间、伦理和学术规范方面的主要风险。

**九、下一步计划**

按优先级排列需要完成的核查任务。

请明确区分已经得到材料支持的内容和仍然只是计划或假设的内容。

不要为了使提纲看起来完整而虚构参考文献、研究发现、统计数据或创新点。

## 指令 22：模拟导师对选题提出质疑

我的候选题目是：【填写】。

我已经准备的选题论证材料是：【粘贴】。

请从论文指导的角度，对选题提出具体而严格的问题。

请优先检查：

1. 为什么要研究这个问题？
2. 现有文献已经解决了哪些问题？
3. 你的研究与最相关的已有研究有什么区别？
4. 为什么选择这个研究对象？
5. 为什么选择这种方法？
6. 你实际能够获得什么资料？
7. 如果数据无法获取，是否有备选方案？
8. 哪些结论可能超出研究证据所支持的范围？
9. 当前题目是否仍然过大？
10. 你如何证明自己的研究判断有依据？

每个问题请说明：

- 质疑的具体内容。
- 它针对选题的哪个缺陷。
- 需要准备什么材料才能回答。
- 什么样的证据可能支持或推翻当前方案。

不要预设当前选题一定正确，也不要直接替我编写一套看似完整的回答。

最后请形成一份选题讨论清单，供我在与指导教师沟通前自行准备。

## 指令 23：根据实际反馈修改候选选题

我与指导教师讨论后，收到了以下反馈：

【粘贴实际反馈】

当前候选题目是：【填写】

已经掌握的文献、数据和研究条件是：【填写】

请帮助我准确理解反馈，并制定修改方案。

第一步：将反馈拆解为具体问题，例如研究范围过大、理论基础不足、研究对象不合适、数据无法获取或研究价值不明确。

第二步：区分必须解决的问题、可以优化的问题和暂时无法判断的问题。

第三步：逐项说明有哪些修改方向，以及修改后会对研究目标、方法、材料和工作量产生什么影响。

第四步：检查修改后的题目是否仍然与我的专业、研究条件和学校要求匹配。

第五步：提出需要进一步核实的证据和待确认事项。

不要将指导教师的意见擅自改写成与原意相反的结论，也不要为了保留原题目而忽视实质性问题。

最终请输出：

| 反馈内容 | 实际问题 | 修改方案 | 需要补充的证据 | 潜在代价 |
| -------- | -------- | -------- | -------------- | -------- |
|          |          |          |                |          |

重点是使修改后的选题更明确、更可行，而不是仅仅改变标题措辞。

# 十二、完整使用案例：从宽泛兴趣到可研究问题

下面用一个虚构的练习场景演示如何依次使用 Prompt。

**注意：以下只是展示选题推理方法，不表示这个方向目前存在已证实的研究空白，也不代表某个具体题目已经通过文献核查。**

假设一名工商管理专业的本科生：

- 对短视频平台和消费者行为感兴趣。
- 有基础的市场营销知识。
- 可以接触一部分在校学生。
- 能够完成基础问卷调查。
- 时间有限，不适合开展大规模实验。
- 尚未核查该方向的系统文献。

## 第一步：从兴趣形成方向

最初的想法：

“我想研究短视频和消费者行为。”

这里并没有明确的研究对象、问题或方法，因此还不能直接认定为成熟题目。

可以使用 Prompt 02 和 Prompt 04，逐步识别与消费者决策、内容特征、信息可信度及购买意愿有关的问题线索。

这一阶段的产出不是最终题目，而是一张有待核查的问题清单。

## 第二步：把方向变成问题

假设进一步选择“短视频平台的本地餐饮探店内容”。

仍然过于宽泛，因为它可能涉及内容类型、信息可信度、品牌态度、购买意愿、实际到店行为等多个问题。

使用 Prompt 05 后，可以把问题进一步限定为：

“消费者对探店内容的感知真实性，与其到店意愿之间存在怎样的关系？”

这只是一个研究问题示例，尚未说明相关关系确实存在，也没有证明该问题已经具有创新性。

## 第三步：制定真实的文献检索方案

使用 Prompt 08，围绕以下概念设计检索词：

- 短视频或社交媒体内容。
- 感知真实性或信息可信度。
- 消费者决策。
- 到店意愿或购买意愿。
- 相关理论及测量方式。

然后在实际可访问的学术数据库中执行检索，保存真实的文献记录。

如果发现已有研究已经充分覆盖相同的问题，应当继续寻找有依据的差异，或者考虑其他问题，而不是仅仅通过更换一个学校或城市来宣称创新。

## 第四步：分析文献，而不是让 AI 编造研究空白

使用 Prompt 09 和 Prompt 10，整理真实论文中的研究对象、方法、结论与局限。

可能需要进一步核查的问题包括：

- 已有研究是否使用相同概念？
- 不同研究中的测量方法是否一致？
- 研究结果是否存在差异？
- 是否有合理依据进一步限定某一人群或情境？
- 自己是否具备获取样本和进行分析的条件？

只有检索与分析得到足够证据之后，才能判断该方向是否值得继续。

## 第五步：评估数据和研究方法

如果计划采用问卷调查，必须提前检查：

- 研究对象是否明确。
- 问卷内容是否有可靠来源。
- 样本招募是否现实可行。
- 目标样本是否能够支持预期分析。
- 是否需要获得相应许可。
- 如何保护受访者个人信息。
- 问卷结果能否回答研究问题。

如果只能获得单一时期的便利样本，研究结果可能只能支持特定样本中的关系或差异，不能轻率地推断因果关系或推广至所有消费者。

## 第六步：评估最终候选题目

假设暂时形成以下候选标题：

“短视频探店内容的感知真实性与大学生餐饮到店意愿的关系研究”。

这个标题比最初的宽泛方向更明确，但仍有必要核查：

- “感知真实性”如何定义和测量？
- “大学生”是否需要进一步限定研究范围？
- 研究对象是所有大学生，还是某个可获取样本？
- 相关研究是否已经回答了相同问题？
- 为什么选择餐饮场景？
- 问卷数据是否足以支撑预期结论？

此时应使用 Prompt 12、Prompt 14、Prompt 16 和 Prompt 18，完成可行性、风险和概念检查。

**这个案例最值得学习的地方，是每一步都在减少不确定性，而不是每一步都在追求更漂亮的题目。**

# 十三、三个容易被忽略的 AI 使用问题

## 1. 不要让 AI 只给答案，要让它展示依据

当 AI 说“这个选题具有创新性”时，应追问：

“你根据什么材料判断它具有创新性？请列出支持这一判断的实际文献或证据。如果没有经过检索，请撤回确定性表述，改为说明需要核实什么。”

当 AI 说“这个题目很容易完成”时，应追问：

“这个判断依赖哪些具体条件？如果样本不足、数据无法获取或实验失败，研究还能否完成？”

这些追问比单纯要求 AI 生成更多题目更有价值。

## 2. 不要把学术词汇丰富程度当成研究质量

下列表述不应直接当作研究价值的证明：

- 构建多维度分析框架。
- 探索作用机制。
- 建立综合评价模型。
- 提出优化路径。
- 填补现有研究空白。
- 推动高质量发展。

这些词语可能出现在合格论文中，但只有当研究问题、理论依据、数据和方法能够支撑它们时，才具有实质意义。

对于本科论文，一个范围明确、能够用真实证据回答的问题，通常比一个概念繁多、但无法完成论证的题目更合适。

## 3. 不要把 AI 的回答当成研究证据

AI 可以帮助你提出假设，但不能把假设自动变成事实。

例如：

“某因素可能影响某种行为”，只是待检验的研究设想。

“已有研究证明某因素影响某种行为”，则需要真实文献作为依据。

“该领域尚无相关研究”，更需要足够全面、可复核的文献检索才能支持。

三者必须严格区分。

# 十四、附录：最重要的操作原则

1. 先明确研究条件，再探索题目。
2. 先形成问题线索，再撰写标题。
3. 先检索真实文献，再判断创新性。
4. 先核查数据和资源，再承诺研究方案。
5. 先明确研究问题，再选择研究方法。
6. 要求 AI 标注不确定性，不要接受没有依据的肯定。
7. 把复杂研究拆成可检查的小任务。
8. 保留真实的检索记录和自己的判断过程。
9. 任何引用、数据、研究发现和法律规范都要核查来源。
10. 最终选题应当符合学校要求，并且确实是自己能够理解、解释和完成的研究。

**最后的判断标准：** 当你能够清楚回答“我研究什么、为什么研究、别人研究到什么程度、我能获得什么证据、我准备怎样回答这个问题，以及我能否按时完成”时，你才真正接近一个成熟的论文选题。
