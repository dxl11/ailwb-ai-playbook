# AI 写开题报告完整指令手册

## 从选题分析、文献研究到正文撰写、质量验收

## 一、使用原则

这套指令适用于本科、硕士等常见学位论文的开题报告准备。具体章节、字数、格式以及评价要求，以学校模板和导师的明确要求为准。

使用前，先记住四条原则：

1. 不要让 AI 仅凭论文题目直接生成完整报告。先完成研究问题、文献依据和研究方案，再写正文。
2. 不要让 AI 凭空编造文献、数据和研究结论。无法核验的信息必须标记出来。
3. 不要把研究计划写成已经完成的研究。开题阶段只能说明拟开展什么研究，以及准备如何开展。
4. 不要因为文本流畅、章节齐全，就认为报告已经合格。必须检查研究问题、文献依据、研究方法、实施条件和学校要求。

建议按本手册的顺序分阶段使用。每个阶段结束后，再进入下一阶段。

# 第二部分：建立 AI 的工作规则

## 指令 1：开题报告总指令与学科适配

这是整套流程的基础指令。开始新任务时，优先发送。

你现在是一名具有学术研究经验的论文指导顾问，熟悉选题论证、文献研究、理论框架、研究方法、研究设计、学术写作和开题报告审查。

你的任务不是简单生成一份格式完整、语言流畅的开题报告，而是协助我形成一份研究问题明确、证据可靠、逻辑严谨、研究方案可执行、符合学校要求的开题报告。

请严格遵守以下规则。

### 1. 先识别学科和研究类型

在正式设计研究方案之前，先确认：

- 所属专业和学科领域。
- 学历层次。
- 研究对象和核心问题。
- 研究属于定量研究、定性研究、混合研究、理论研究、规范分析、历史研究、文本分析、实验研究，还是其他类型。
- 学校明确规定的章节、格式和评价要求。

根据研究类型选择相应的研究框架，不得机械套用统一模板。

例如：

- 定量研究应重视变量定义、测量方式、数据来源、分析方法及研究假设的合理性。
- 定性研究应重视案例选择、资料获取、分析程序、编码或主题形成过程以及研究可信度。
- 文学、历史、哲学等研究应重视原始文本、史料、理论阐释和论证依据，不得强行套用问卷和变量。
- 法学研究应重视法律规范、判例、规范解释、比较法依据及法律论证的完整性。
- 计算机、工程和实验研究应重视技术方案、实验条件、基线方法、评价指标、验证方案和可复现性。
- 艺术、设计及应用型研究应重视创作或实施过程、设计依据、成果形式、实践条件和评价标准。

以上仅为适配方向，具体采用什么框架，需要结合研究对象判断。

### 2. 关于学术真实性

1. 不得虚构作者、论文标题、期刊、出版社、年份、DOI、页码、数据、政策文件或研究结论。
2. 不得把未经核实的信息表述为已确认的事实。
3. 不得根据文献标题猜测论文的具体结论、样本或研究方法。
4. 不得把摘要当作已经阅读全文的证据。
5. 不得将研究假设、个人分析、已有文献结论和实际研究发现混为一谈。
6. 对无法核实的内容，必须标记“待核实”，并说明具体需要核实什么。
7. 对没有实际完成的调查、实验或数据分析，不得编造结果。
8. 对重要的事实性判断，应尽可能提供可追溯的来源。

### 3. 关于研究设计

1. 研究背景必须逐步导向明确的研究问题。
2. 研究意义必须与研究内容相对应。
3. 文献综述必须形成主题归纳、观点比较和研究述评，而不是简单罗列作者。
4. 研究目标、研究问题、研究内容、理论框架和研究方法必须保持一致。
5. 研究方法必须能够回答拟提出的研究问题。
6. 研究资料、数据、样本、案例或原始文本必须具有实际获取途径。
7. 创新点必须建立在真实的研究差异和合理的证据基础上。
8. 研究进度必须符合学校时间要求和现实条件。
9. 如果研究设计存在根本性问题，应先指出问题，再讨论正文写作。
10. 不得通过增加字数或复杂术语掩盖研究设计的缺陷。

### 4. 关于写作风格

- 使用符合学术规范的中文书面表达。
- 论述准确，逻辑清晰，层次分明。
- 避免反复使用空泛套话。
- 不为突出价值而夸大研究贡献。
- 不通过重复概念或重复结论凑字数。
- 不随意改变专业术语。
- 不得为了追求措辞多样而改变原始观点的含义。

### 5. 关于工作流程

请按以下顺序执行：

第一步：检查任务要求、学校模板和已有资料。

第二步：识别学科类型，确定适用的研究范式。

第三步：分析选题，明确研究范围和核心问题。

第四步：制定文献检索计划，收集并核验真实文献。

第五步：形成文献综述及理论或概念框架。

第六步：确定研究目标、研究内容、研究方法和技术路线。

第七步：对研究方案进行反向压力测试，主动寻找缺陷。

第八步：建立开题报告提纲。

第九步：按章节逐步撰写正文。

第十步：检查论证、证据、引用、语言和格式。

第十一步：根据学校评价要求进行最终验收。

每个阶段结束后，输出：

- 本阶段已确认的内容。
- 仍需补充的资料。
- 尚未解决的问题。
- 可能影响研究质量的风险。
- 是否具备进入下一阶段的条件。

对于会改变研究方向的重大信息，不要擅自假定。如果缺少的信息不会影响当前工作，则可以先完成可执行的部分。

请根据我提供的基本资料开始工作，不要重复询问已经明确的信息。

# 第三部分：选题与研究问题

## 指令 2：分析论文题目是否合理

使用时机：已经有论文题目，但不确定是否适合研究。

我的专业是：[填写]。

学历层次：[填写]。

论文题目：[填写]。

学校要求：[填写]。

研究条件：[填写]。

请系统分析这个选题。

### 一、题目拆解

分析题目中的核心概念、研究对象、研究范围、研究情境和潜在研究方向。

判断是否存在概念模糊、范围过大、对象不明确、研究问题不清晰等情况。

### 二、选题可行性

分别评价：

1. 研究价值：为什么值得研究，具体价值是什么。
2. 文献基础：是否存在可供研究的相关文献。
3. 资料条件：必要数据、案例或原始材料能否获取。
4. 研究难度：是否符合我的学历层次和能力条件。
5. 时间要求：能否在规定时间内完成。
6. 研究风险：可能遇到哪些理论、数据、方法或实施问题。

### 三、题目优化

提出三个备选方向：

- 方案 A：保留原题，优化表达。
- 方案 B：缩小研究范围，提高可执行性。
- 方案 C：更换研究切入点，突出具体问题。

每个方案均需说明研究对象、核心问题、优势、局限、所需证据和实施条件。

### 四、反向判断

主动寻找该选题可能不成立的理由。

判断它是否只是一个宏观主题，而不是明确的研究问题；是否存在文献不足、材料无法获取或研究范围过大的风险。

### 五、最终建议

对各方案进行比较，并推荐一个最合适的方向。

特别要求：不能仅凭题目判断研究创新性。需要进一步检索文献、核实资料条件，才能判断该选题是否具有真实的研究空间。

## 指令 3：从题目提炼核心研究问题

使用时机：题目已经确定，但不知道论文究竟应该研究什么。

论文题目：[填写]。

研究对象：[填写]。

已有资料：[填写]。

请帮助我明确核心研究问题。

要求：

1. 拆解题目的核心概念、研究对象和研究范围。
2. 提出一个核心研究问题及 3—5 个有逻辑联系的子问题。
3. 根据学科特点组织问题，不机械套用“现状—问题—原因—对策”。
4. 说明每个问题需要哪些证据才能回答。
5. 说明每个问题可以采用什么研究方法。
6. 判断每个问题是否过于宽泛、相互重复或难以验证。
7. 检查问题是否超出实际研究条件。

请使用以下表格：

| 研究问题 | 需要回答的具体内容 | 所需证据 | 研究方法 | 可行性判断 |
| -------- | ------------------ | -------- | -------- | ---------- |
|          |                    |          |          |            |

最后形成经过优化的研究问题体系，并解释不同问题之间的关系。

不要把“研究某某的现状、问题及对策”当成完整研究设计。必须进一步明确研究对象、分析依据和结论形成方式。

# 第四部分：文献检索与研究综述

## 指令 4：制定文献检索方案

使用时机：不知道应该检索什么文献、用什么关键词。

论文题目：[填写]。

核心研究问题：[填写]。

所属学科：[填写]。

请制定可执行的文献检索方案。

### 一、关键词拆解

提供：

- 核心概念关键词。
- 同义词和近义词。
- 专业术语。
- 研究对象相关关键词。
- 方法相关关键词。
- 合适的英文关键词及可能存在的不同译法。

不要只做逐字翻译，要考虑学科语境。

### 二、检索渠道

根据学科选择相应的中文数据库、英文数据库、图书馆目录、期刊官网、政府文件或其他权威来源。

中文文献可以考虑中国知网、万方、维普及相关机构的公开资料。

英文文献可根据学科选择 Web of Science、Scopus、Google Scholar、PubMed 等平台。

不要求所有学科都使用相同数据库。

### 三、检索式设计

提供可直接使用的关键词组合、逻辑运算符和检索字段。

说明不同检索式分别用于查找理论文献、核心研究、研究方法还是最新成果。

### 四、文献筛选标准

明确：

- 纳入标准。
- 排除标准。
- 时间范围及其依据。
- 文献类型和来源的优先级。
- 核心经典文献与最新文献的搭配原则。
- 如何处理重复文献、主题偏离及证据不足的资料。

### 五、检索记录

请设计实际检索记录表，至少包含数据库名称、检索日期、关键词或检索式、筛选条件、初步结果、最终纳入情况及排除理由。

不得把没有执行过的检索写成已经完成的检索。

### 六、文献整理表

设计以下字段：

作者及年份、文献标题、研究主题、研究对象、理论基础、研究方法、主要发现、研究局限、与本论文的关系、核验状态。

最后给出分阶段检索计划及待查清单。

## 指令 5：对已有文献进行分类和分析

使用时机：已经找到一批论文或研究资料。

论文题目：[填写]。

核心研究问题：[填写]。

文献资料：[粘贴文献条目、摘要、全文摘录或阅读笔记]。

请根据实际提供的文献开展分析。

### 一、相关性判断

将文献分为：

- 直接研究本论文核心问题的文献。
- 提供理论依据的基础文献。
- 提供方法参考的文献。
- 提供背景信息的辅助文献。
- 相关性较弱、不宜重点使用的文献。

### 二、主题归纳

按照研究主题、理论视角、研究对象、研究方法、观点差异或研究发展脉络进行分类。

不要简单按照作者姓名或发表年份罗列。

### 三、研究成果比较

分析不同研究之间的共识、分歧、发展关系及适用条件。

如果不同研究得出不同结论，检查其研究对象、样本、时间、环境、测量指标及方法是否存在差异。

不得为了形成统一结论而隐藏分歧。

### 四、研究局限与空白

分析现有研究可能存在的限制，例如研究对象范围、材料覆盖、理论解释、方法局限或适用情境。

每项判断必须有具体文献或检索记录支撑。

如果尚无充分证据，应将其标记为待验证的研究方向，不要直接称为已被证明的研究空白。

### 五、输出结果

| 文献类别 | 代表性研究 | 主要观点 | 研究共识或分歧 | 已有局限 | 对本论文的启示 |
| -------- | ---------- | -------- | -------------- | -------- | -------------- |
|          |            |          |                |          |                |

最后区分哪些结论可以直接使用，哪些需要补充文献，哪些不能作为确定性论据。

不得自行补全没有提供的全文内容、样本信息或具体结论。

## 指令 6：撰写国内外研究现状

使用时机：已经整理好真实文献，需要撰写开题报告中的研究现状。

论文题目：[填写]。

核心研究问题：[填写]。

国内文献：[粘贴已核验资料]。

国外文献：[粘贴已核验资料]。

字数要求：[填写]。

请根据已有文献撰写国内外研究现状。

### 一、国内研究现状

根据研究主题或理论视角分类，归纳主要观点、理论基础、方法和结论。

### 二、国外研究现状

根据实际文献情况，分析相关研究的发展、理论视角、研究方法和主要发现。

不能仅凭文献来源国家判断其研究质量。

### 三、国内外研究述评

比较国内外研究的共识、分歧、发展关系、适用范围及局限。

说明这些研究对本论文的启示，并自然引出本论文拟研究的问题。

### 四、写作约束

1. 不得逐篇机械罗列文献。
2. 主要观点必须有相应文献支持。
3. 研究不足必须有依据。
4. 不得将“没有检索到”直接等同于“不存在相关研究”。
5. 不得将一般性选题差异夸大为学术创新。
6. 不得为了突出本论文而夸大已有研究的不足。
7. 引用必须能对应到真实文献条目。
8. 摘要内容与全文内容必须区别对待。

最终输出完整段落，并标注需要进一步核验的引用和论断。

# 第五部分：理论框架与研究设计

## 指令 7：建立理论基础与概念分析框架

使用时机：需要明确论文采用什么理论、核心概念如何定义，以及理论如何支撑研究。

论文题目：[填写]。

研究问题：[填写]。

现有文献：[粘贴]。

研究目标：[填写]。

拟采用的方法：[填写]。

请完成以下任务。

### 一、判断是否需要理论框架

根据学科和研究类型判断本研究是否需要明确的理论框架、概念框架、分析框架或研究假设。

不能为了让开题报告显得完整而强行套用某种理论。

### 二、选择候选理论

识别与研究问题相关的理论，并说明：

- 理论主要解释什么。
- 适用条件是什么。
- 有哪些局限。
- 与本研究的关系是什么。
- 为什么选择它而不是其他候选理论。

### 三、界定核心概念

明确核心概念的定义、适用范围和使用方式。

对不同文献中的定义进行比较，不得把存在争议的概念写成只有一种解释。

### 四、建立分析框架

根据研究类型选择相应框架。

定量研究：明确理论变量、关系、测量方式及研究假设。

定性研究：明确主要分析概念、观察维度、编码思路或主题分析框架。

# 第九部分：推荐的执行顺序

为了减少重复劳动，建议按照以下顺序使用整套指令。

| 阶段       | 使用指令   | 进入下一阶段的条件                                 |
| ---------- | ---------- | -------------------------------------------------- |
| 资料准备   | 指令 0—1   | 基本信息和学校要求已明确，学科类型已识别           |
| 选题设计   | 指令 2—3   | 题目范围和核心问题基本确定                         |
| 文献研究   | 指令 4—6   | 有可追溯的文献依据，初步研究述评成立               |
| 理论与方法 | 指令 7—12  | 框架、目标、方法、资料条件基本一致，主要风险已评估 |

后续任务必须以该状态表为依据。如果发现新证据与原方案冲突，应先讨论是否需要调整研究设计，而不是直接更改正文。

# 第十部分：使用过程中的六条实战规则

## 1. 学校模板优先于通用模板

先提供学校的真实要求，再让 AI 规划结构。没有模板时，才采用通用结构。

## 2. 先找文献，再写研究现状

不能让 AI 根据题目直接编出国内外研究现状。应先检索真实文献，再让它分类、比较、归纳。

## 3. 先确认研究设计，再扩写正文

研究问题和方法尚未确定时，不要急着扩写研究背景、意义和创新点。

## 4. 一次只要求完成一个明确任务

不要一次性粘贴所有指令并要求生成全文。明确当前要完成哪一项任务、使用哪些材料、字数是多少以及需要什么格式。

## 5. 重要判断必须能够追溯

对关键事实、研究结论和数据，始终追问：依据是什么？来自哪里？是否核实？是否真的支持当前论断？

## 6. AI 的输出不能替代研究本身

AI 可以协助组织、比较、分析和修改，但不能替代真实文献阅读、研究材料收集、数据分析、学术判断和最终责任。

学校关于 AI 辅助写作、引用和披露的规定也必须遵守。

# 最终执行原则

开题报告的完成顺序应当是：

**明确研究问题 → 建立文献依据 → 确定理论与概念框架 → 设计研究方法 → 检查研究可行性 → 组织提纲 → 分章节写作 → 核查证据 → 修改与验收。**

不要颠倒这个顺序。

一份合格的开题报告，至少需要清楚回答以下四个问题：

1. 为什么值得研究？
2. 现有研究已经知道什么，还有什么问题需要进一步研究？
3. 准备通过什么资料、方法和分析步骤回答这个问题？
4. 这项研究在现有时间、资源和学校要求下能否实际完成？

如果这四个问题都能得到有依据、可执行且前后一致的回答，才具备形成高质量开题报告的基础。
