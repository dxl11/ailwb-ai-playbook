# 贡献指南 / Contributing Guide

## 中文

感谢你考虑为 Ailwb AI Playbook 做贡献。本仓库只收录 Markdown 形式的论文写作 AI 指令与相关文档。

### 贡献规则

1. **说明场景与目标**  
   提交指令时，请说明适用场景和使用目标，便于他人判断是否适用。

2. **中英双语成对提交**  
   每条指令的中文与英文版本分别保存在同一条目目录下的 `zh-CN.md` 和 `en-US.md`。

3. **语义一致，而非机械翻译**  
   中英文版本应表达相同的目标、约束和输出要求，而不是机械逐字翻译。

4. **内容合规**  
   不要提交侵犯他人版权、包含隐私数据或可能误导用户的内容。

5. **遵守学术规范**  
   涉及论文写作时，请强调核对来源、检查事实，并遵守学校和期刊的学术规范。AI 输出不能替代本人的研究与写作责任。

6. **提交前自检**  
   提交前请检查 Markdown 排版、链接，以及中英文版本是否齐全。

### 建议的提交流程

1. Fork 本仓库并创建分支。
2. 在对应分类目录下新增条目目录，放入 `zh-CN.md` 与 `en-US.md`。
3. 确认文档清晰、可复用，且不包含示例性的虚假指令填充。
4. 发起 Pull Request，并在说明中简述适用场景与改进点。

如有疑问，可通过 Issue 与维护者沟通。

## English

Thank you for considering a contribution to Ailwb AI Playbook. This repository only accepts Markdown prompts and related documentation for academic paper writing.

### Contribution Rules

1. **State the scenario and goal**  
   When submitting a prompt, describe the intended use case and objective so others can judge fit.

2. **Ship Chinese and English as a pair**  
   Save the Chinese and English versions of each prompt as `zh-CN.md` and `en-US.md` in the same entry directory.

3. **Same meaning, not word-for-word translation**  
   The two language versions should express the same goals, constraints, and output requirements—not a mechanical literal translation.

4. **Stay compliant**  
   Do not submit content that infringes copyright, includes private data, or may mislead users.

5. **Uphold academic integrity**  
   For thesis-related prompts, emphasize verifying sources, checking facts, and following institutional and journal academic standards. AI output does not replace the author’s research and writing responsibility.

6. **Self-check before submitting**  
   Before opening a PR, check Markdown formatting, links, and that both language versions are complete.

### Suggested Workflow

1. Fork the repository and create a branch.
2. Add an entry directory under the appropriate category, with `zh-CN.md` and `en-US.md`.
3. Ensure the docs are clear and reusable, without placeholder or fabricated prompt filler.
4. Open a Pull Request and briefly describe the scenario and what you improved.

Questions can be raised via Issues.
