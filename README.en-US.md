# Ailwb AI Playbook

[中文](README.md) | [English](README.en-US.md)

## About

Ailwb AI Playbook is an open-source repository of AI prompts for undergraduate thesis and academic paper writing. It collects and shares stage-oriented prompts as Markdown documents only—not a website or software project.

## Goals

Help users find, learn, and apply AI prompts by thesis-writing stage, from topic selection through defense.

## Categories

Currently available prompts:

| Category | Prompt |
|----------|--------|
| Topic selection | [Undergraduate Thesis Topic Selection AI Prompts](prompts/01-topic-selection/undergraduate-thesis-topic-selection/en-US.md) |

Other writing stages will be listed here once official prompts are added.

## How to Use

1. Click a prompt link in the table above to open the file directly.
2. Each official prompt provides both `zh-CN.md` (Chinese) and `en-US.md` (English); use the language that fits your workflow.

## How to Contribute

Contributions are welcome: new prompts, improvements to existing content, or documentation fixes. See [CONTRIBUTING.en-US.md](CONTRIBUTING.en-US.md) for guidelines.

## Current Status

One topic-selection prompt set is available. Other categories do not yet include official prompts.
