# Ailwb AI Playbook

## 中文

### 项目简介

Ailwb AI Playbook 是一个面向大学生的论文写作 AI 指令开源仓库，用于持续整理和分享与论文写作相关的 AI 指令。本仓库仅保存 Markdown 文档，不是网站或软件项目。

### 项目目标

帮助用户按论文写作阶段查找、学习和使用 AI 指令，降低从选题到答辩各环节中使用 AI 的试错成本。

### 内容分类

指令按写作阶段存放在 `prompts/` 目录下：

| 目录 | 说明 |
|------|------|
| `01-topic-selection` | 选题 |
| `02-research-proposal` | 研究计划 / 开题 |
| `03-literature-search-reading` | 文献检索与阅读 |
| `04-literature-review` | 文献综述 |
| `05-thesis-outline` | 论文大纲 |
| `06-research-methods-data-analysis` | 研究方法与数据分析 |
| `07-academic-writing-revision` | 学术写作与修改 |
| `08-citations-references-formatting` | 引用、参考文献与格式 |
| `09-final-check` | 终稿检查 |
| `10-presentation-defense` | 答辩与汇报 |

补充说明文档可放在 `docs/` 目录。

### 如何使用

1. 进入 `prompts/` 下与当前写作阶段对应的分类目录。
2. 找到目标指令条目。
3. 每条正式指令未来将提供 `zh-CN.md`（中文）与 `en-US.md`（英文）两种语言版本，按需选用。

### 如何贡献

欢迎提交新的指令、改进现有内容或修正文档。具体规则请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。

### 当前状态

目前仅建立项目目录框架，尚未收录正式指令。各分类目录暂时为空，后续由仓库维护者自行添加。

### 开源许可证

开源许可证待维护者确认 / Open-source license to be selected by the maintainer.

## English

### About

Ailwb AI Playbook is an open-source repository of AI prompts for undergraduate thesis and academic paper writing. It collects and shares stage-oriented prompts as Markdown documents only—not a website or software project.

### Goals

Help users find, learn, and apply AI prompts by thesis-writing stage, from topic selection through defense.

### Categories

Prompts are organized under `prompts/` by writing stage:

| Directory | Description |
|-----------|-------------|
| `01-topic-selection` | Topic selection |
| `02-research-proposal` | Research proposal / prospectus |
| `03-literature-search-reading` | Literature search and reading |
| `04-literature-review` | Literature review |
| `05-thesis-outline` | Thesis outline |
| `06-research-methods-data-analysis` | Research methods and data analysis |
| `07-academic-writing-revision` | Academic writing and revision |
| `08-citations-references-formatting` | Citations, references, and formatting |
| `09-final-check` | Final check |
| `10-presentation-defense` | Presentation and defense |

Additional documentation may go in `docs/`.

### How to Use

1. Open the category folder under `prompts/` that matches your current writing stage.
2. Locate the prompt entry you need.
3. Each official prompt will eventually provide both `zh-CN.md` (Chinese) and `en-US.md` (English); use the language that fits your workflow.

### How to Contribute

Contributions are welcome: new prompts, improvements to existing content, or documentation fixes. See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

### Current Status

This repository currently contains only the directory framework. No official prompts have been added yet. Category folders are empty for now and will be filled by maintainers later.
