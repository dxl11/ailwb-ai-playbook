# Ailwb AI Playbook

[中文](README.md) | [English](README.en-US.md)

## 项目简介

Ailwb AI Playbook 是一个面向大学生的论文写作 AI 指令开源仓库，用于持续整理和分享与论文写作相关的 AI 指令。本仓库仅保存 Markdown 文档，不是网站或软件项目。

## 项目目标

帮助用户按论文写作阶段查找、学习和使用 AI 指令，降低从选题到答辩各环节中使用 AI 的试错成本。

## 内容分类

目前已收录的指令如下：

| 分类 | 指令 |
|------|------|
| 选题 | [大学生论文选题 AI 指令](prompts/01-topic-selection/undergraduate-thesis-topic-selection/zh-CN.md) |
| 开题报告 | [AI 写开题报告完整指令手册](prompts/02-research-proposal/research-proposal-complete-handbook/zh-CN.md) |

其他写作阶段待有正式指令后再在此介绍。

## 如何使用

1. 点击上表中的指令链接，直接打开对应文件。
2. 每条正式指令提供 `zh-CN.md`（中文）与 `en-US.md`（英文）两种语言版本，按需选用。
